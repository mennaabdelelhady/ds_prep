# Zero to Hero: ITI Data Science 2026 Roadmap

An interactive, animated mission log for the **ITI Intensive Code Camp: Data Science 2026** track (668 hours, about 5 months). Tick off missions, watch the progress ring fill, and level up from Civilian to Hero.

- Every course from the official track overview, each with study sub-tasks and free resources
- Pre-application "Origin Story" checklist with the Maharatech prerequisite links
- Progress saved in your browser (localStorage), no backend
- Filters, reset, reduced-motion support

## Run it
Open `index.html` in a browser. No build step.

## Deploy on GitHub Pages
Push to `main`, then in **Settings > Pages** choose **GitHub Actions**. The included workflow publishes the site.

## Customize
Edit the `PHASES` array at the top of the script in `index.html` to add missions or links.
